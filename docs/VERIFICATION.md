The v0.2.0 source suite contains 55 API/export/appearance/filesystem tests and 7 Electron interaction tests, all passed locally on macOS arm64 and on all four native CI runners. The initial v0.1.0 suite contained 43 API/export/filesystem tests and 5 Electron interaction tests. CI stores per-platform screenshot evidence as artifacts. Fixture tests never establish access to all content of a real account.

A public release is gated on the recorded live verification and successful platform jobs. Source and package preparation may happen privately before that gate. A completed save can contain notices or a requested message limit; inspect the manifest before treating an archive as complete.

## v0.2.0 release build

The application build is commit `03702e1990c099b29490537288a5eb5dcb81a4a3`, verified in [GitHub Actions run 40810182942](https://github.com/H644b/DisDown/actions/runs/40810182942). All four native platform jobs passed build/typecheck, 55 API/export/appearance/filesystem tests, 7 Electron interaction tests, installer packaging, and packaged-app launch. The eight v0.2.0 installers come from that run. Later documentation-only commits record the design system and verification without changing application code.

The connected macOS session returned Blurple Twilight (preset22, Darker base). All 109 available server images loaded at the complete rounded 44×44 bounds. Account appearance reading and icon coverage were checked without extracting or persisting credentials. Synthetic settings tests cover the other base modes, custom data, malformed payloads, and recovery; every Nitro preset was not visually compared with a separate live account.

The independent redesign review identified two material issues: faint unchecked selection controls and scrolling content bleeding through the gradient footer. Its verdict pass scored both resolved, with a ship disposition at that fix-list scope. Sample captures cover dark, light, Blurple Twilight, the export path, the themed picker, and the minimum desktop size. The Mac arm64 download also passed strict signature integrity verification and contains the font license. Apple notarization and Windows publisher signing are not provided. Manual installer UI on every supported OS was not separately exercised.
