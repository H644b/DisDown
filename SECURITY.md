# Security reporting

Do not include tokens, real message bodies, private server names, or personal archives in public issues.

For a reproducible issue, report the affected version, platform, and a minimal example using the sample workspace or synthetic data. If details are sensitive, first open an issue requesting a private contact method without disclosing those details.

This application never needs you to send a token to its maintainer. If a token is exposed, revoke or rotate it through Discord before sharing further evidence.
